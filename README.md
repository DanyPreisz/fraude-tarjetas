# Detección de Fraude en Tarjetas de Crédito

Proyecto de clasificación desbalanceada listo para Google Colab. Incluye EDA, modelos y SHAP.

## Abrir en Google Colab

[![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/DanyPreisz/fraude-tarjetas/blob/main/fraude_tarjetas_colab.ipynb)

## Contenido

- EDA (distribución, histograma, correlación)
- Manejo de desbalance (class_weight)
- Modelos: Logistic Regression, Random Forest
- Matriz de confusión + classification report + PR-AUC
- Feature importance
- **SHAP** (summary plot)
- Conclusiones

Dataset: Credit Card Fraud Detection

Rango esperado: ROC-AUC ~0.95–0.99 | PR-AUC ~0.70–0.85
